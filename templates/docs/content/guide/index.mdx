## The sidebar comes from the file tree

Each top-level directory becomes a labelled section; directories nested inside it
become collapsible groups. The section name comes from the directory name and the
`index.mdx` inside it is listed as an ordinary page, so the two never repeat the
same label:

```text
content/guide/index.mdx      →  section "Guide", first item "Overview"
content/guide/advanced/…     →  collapsible "Advanced" inside "Guide"
```

<AccordionGroup>
  <Accordion title="How do I reorder pages?">
    Set `order` in the frontmatter. Lower numbers come first, pages without an
    `order` come last, and ties are sorted by label.
  </Accordion>
  <Accordion title="How do I add an icon to a sidebar entry?">
    Set `icon` to any name from the curated icon set, for example
    `icon: Rocket`.
  </Accordion>
  <Accordion title="How do I hide a page?">
    `sidebar: false` keeps it out of the sidebar, the blog list and the feeds, but
    the page is still published at its URL.
  </Accordion>
</AccordionGroup>
