These components are injected into every `.mdx` file through `MDXProvider`, so
they work without an import. To replace one, just import your own — an explicit
import always wins.

### CodeGroup

`CodeGroup` turns a set of code blocks into tabs, labelled with each block's
`title`:

<CodeGroup>
```bash title="bun"
bun add -g novon
```

```bash title="npm"
npm install -g novon
```

```bash title="pnpm"
pnpm add -g novon
```
</CodeGroup>

## Emphasis

### Callouts

<Note>Neutral information.</Note>

<Info>Background context.</Info>

<Tip>Something that makes life easier.</Tip>

<Warning>Something that will break.</Warning>

<Caution>Something to be careful about.</Caution>

<Danger>Destructive or irreversible.</Danger>

`Callout` also takes a `type` of `note`, `info`, `tip`, `success`, `warning`,
`caution` or `danger`, plus an optional `title` and `icon`.

### Badge

Status badges: <Badge>New</Badge> <Badge variant="secondary">Beta</Badge>
<Badge variant="outline">Draft</Badge> <Badge variant="success">Stable</Badge>
<Badge variant="warning">Deprecated</Badge>

### Term

An inline definition: <Term tip="Content Delivery Network">CDN</Term> is a
network of edge servers.

### Icon

Inline icons by name: <Icon icon="Rocket" /> <Icon icon="Shield" />
<Icon icon="Database" /> <Icon icon="Zap" />

The curated set covers the common cases. For anything else, pass a component:
`<Icon icon={MyIcon} />`.

## Site data

### PostList and TagList

Both read the site index from context, so they need no props. They are most
useful in the blog template:

```mdx
<PostList limit={5} title="Latest posts" />

<TagList />
```

## Using the shadcn/ui primitives

The components novon itself is built from are exported too, for custom pages:

```mdx
import { Button, Card, CardContent, CardHeader, CardTitle, Tabs, TabsList,
         TabsTrigger, TabsContent } from 'novon'

<Button variant="outline" size="sm">Click me</Button>
```

Available primitives: `Button`, `Badge`, `Card` (with `CardHeader`,
`CardTitle`, `CardDescription`, `CardContent`, `CardFooter`), `Input`, `Kbd`,
`Separator`, `ScrollArea`, `Tabs`, `Accordion`, `Collapsible`, `Tooltip`,
`Dialog` and `Popover` — all built on Base UI.

<Note>
  `Card` inside MDX is the content card from this page. The shadcn/ui container
  is exported as `import { Card } from 'novon'`, which shadows the built-in.
</Note>
