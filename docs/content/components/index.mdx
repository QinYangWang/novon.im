import { Input, Button, Card, CardContent, CardDescription, CardHeader, CardTitle } from 'novon'

Every component below is a [`shadcn/ui`](https://ui.shadcn.com) style primitive built on
[Base UI](https://base-ui.com). They ship inside `novon`, so a site can use them in
MDX, in a custom page or in a theme override without installing anything.

<Preview title="A composed example" description="Primitives drop into any MDX page.">

    <CardDescription>One email, every Friday.</CardDescription>
  </CardHeader>
  <CardContent className="flex flex-col gap-3">
    <Input placeholder="you@example.com" type="email" />
    <Button className="w-full">Subscribe</Button>
  </CardContent>
</Card>

## Design conventions

The set follows a small number of rules so unrelated components still read as one
system. They are the same rules the rest of the theme is built on.

- **One radius scale.** Controls use `rounded-md`, surfaces `rounded-lg` or
  `rounded-xl`, and circles are reserved for avatars, radios and sliders. A
  component never invents its own corner.
- **Hairline borders and flat surfaces.** Boundaries are drawn with `border-border`,
  not shadows. Elevation is reserved for overlays that genuinely float.
- **Monochrome by default.** Light is black on white, dark is white on black.
  Color marks state, action and data, so status tones stay meaningful. Hover and
  selection use the neutral `accent` token.
- **Geist typography.** Headings and prose use Geist, code and identifiers Geist
  Mono. The scale is a few sizes used consistently rather than many one-offs.
- **Sentence case.** Labels, titles and buttons are written the way a person
  speaks, not Title Cased.
- **Keyboard first.** Native elements, visible focus rings, `aria-*` on the
  custom controls and hit areas that meet the 24 by 24 minimum.
