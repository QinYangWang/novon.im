---

Use a card for a destination that benefits from a description. Use an ordinary
Markdown link for references within a sentence. MDX cards need no import.

<Preview title="Related guides">
<CardGroup>
  <Card title="Write content" icon="FileText" href="/guide/content">Frontmatter, Markdown and MDX.</Card>
  <Card title="Deploy a site" icon="Globe" href="/guide/deploying">Publish the generated static files.</Card>
</CardGroup>

```mdx
<CardGroup cols={2}>
  <Card title="Write content" icon="FileText" href="/guide/content">
    Frontmatter, Markdown and MDX.
  </Card>
  <Card title="Deploy a site" icon="Globe" href="/guide/deploying">
    Publish the generated static files.
  </Card>
</CardGroup>
```
</Preview>

`Card` accepts `title`, `icon`, `href`, `horizontal` and `arrow`.
`CardGroup` accepts `cols={1}`, `cols={2}` or `cols={3}` and stacks on narrow screens.
Omit `href` for a non-interactive summary; do not nest links inside a linked card.

<Note>
  The package export `Card` is a lower-level surface for custom themes. Importing
  it shadows the MDX card. Use `MdxCard` when you need the authoring card in React.
</Note>
