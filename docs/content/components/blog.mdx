title: Blog lists

The blog template already supplies a homepage, `/blog` and `/tags/<tag>` pages.
Use these components only when composing a custom homepage or topic index.

```mdx
## Recent writing

<PostList limit={5} />

## Browse by topic

<TagList />
```

`PostList` accepts an optional `limit` and `title`. It reads titles, descriptions
and dates from frontmatter and links to the published posts. `TagList` links to
the generated topic pages; use it with the blog template, which creates those
routes. Drafts are excluded from production builds.

For a custom React theme, import `PostList`, `PostItem`, `PostCard` and `TagList`
from `novon` and pass the posts or tags from `useSite().site` explicitly.
