import { Badge, Table, TableBody, TableCaption, TableCell, TableFooter, TableHead, TableHeader, TableRow } from 'novon'

A table is for reading exact values across consistent rows. Numbers are right
aligned and use tabular figures so the columns line up.

## Usage

<Preview title="Basic" description="A header, a body and a footer total.">

## API

| Component | Element |
| --- | --- |
| `Table` | `div` wrapper + `table` |
| `TableHeader` / `TableBody` / `TableFooter` | `thead` / `tbody` / `tfoot` |
| `TableRow` | `tr` |
| `TableHead` / `TableCell` | `th` / `td` |
| `TableCaption` | `caption` |

`Table` scrolls horizontally inside its own wrapper rather than breaking the
page, and `containerClassName` targets that wrapper. Right align a numeric header
and every cell beneath it, as the example does.
