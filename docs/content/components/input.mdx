import { Input, Label, Textarea } from 'novon'

`Input` and `Textarea` are thin wrappers over the native elements. They keep the
platform's keyboard, selection and autofill behavior and add only the theme's
border, radius and focus ring.

## Usage

<Preview title="Input" description="A single line of text.">

<div className="flex w-full max-w-sm flex-col gap-2">
  <Label htmlFor="email">Email</Label>
  <Input id="email" type="email" placeholder="you@example.com" />
</div>

```mdx
<Label htmlFor="email">Email</Label>
<Input id="email" type="email" placeholder="you@example.com" />
```

</Preview>

## API

| Prop | Type | Default |
| --- | --- | --- |
| `type` | native input types | `text` |
| `aria-invalid` | `boolean` | — |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |

Both components spread every native attribute, so `onChange`, `name`, `required`
and the rest behave exactly as they do on the platform element. Use
[Field](/components/field) when an input needs a description or an error.
