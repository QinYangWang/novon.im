import { Blobatar } from 'novon'

[Blobatar](https://blobatar.dev) turns any string into a stable geometric face:
a name, handle, email or id. The same string always renders the same creature,
so nothing is stored and nothing is fetched. It is the right fallback for
somebody who has not uploaded a picture, not a replacement for one they have.

The default is monochrome. A black body with white eyes, inverted in dark mode so
the mark follows the theme the way the rest of the page does.

## API

| Prop | Type | Default |
| --- | --- | --- |
| `name` | `string` | required |
| `size` | `number` | CSS |
| `fill` | `boolean` — fill the containing box | `false` |
| `monochrome` | `boolean` | `true` |
| `palette` | `{ head?: string; eye?: string; bg?: string }` | — |
| `alt` | `string` | `name` |
| `xstyle` | `StyleXStyles` | — |

The component renders an `<img>`, so a list of hundreds stays a list of images
rather than a few thousand DOM nodes. Use `alt=""` when the name is already next
to it, so a screen reader does not repeat it.

<Note>
  `monochrome` inverts the mark in dark mode with a CSS filter. That keeps one
  asset for both themes without a second request. When you pass `palette`, the
  colours are used as given and nothing is inverted.
</Note>
