import { Button, toast } from 'novon'

A toast confirms something that just happened and then gets out of the way. It
is mounted once by the theme, so a page only has to call `toast()`.

## Usage

<Preview title="Default" description="Title, description and an automatic dismiss.">

<div className="flex flex-wrap gap-3">
  <Button onClick={() => toast({ title: 'Saved', description: 'Your changes are live.' })}>
    Save
  </Button>
  <Button
    variant="outline"
    onClick={() => toast({ title: 'Link copied', duration: 3000 })}
  >
    Copy link
  </Button>
</div>

```mdx
import { Button, toast } from 'novon'

<Button onClick={() => toast({ title: 'Saved', description: 'Your changes are live.' })}>
  Save
</Button>
```

</Preview>

<Preview title="Variants" description="Match the tone to the outcome.">

<div className="flex flex-wrap gap-3">
  <Button variant="outline" onClick={() => toast({ variant: 'success', title: 'Deployed' })}>Success</Button>
  <Button variant="outline" onClick={() => toast({ variant: 'info', title: 'Syncing in the background' })}>Info</Button>
  <Button variant="outline" onClick={() => toast({ variant: 'warning', title: 'Usage at 85%' })}>Warning</Button>
  <Button variant="outline" onClick={() => toast({ variant: 'destructive', title: 'Upload failed', description: 'The file is larger than 10 MB.' })}>Error</Button>

```mdx
toast({ variant: 'success', title: 'Deployed' })
toast({ variant: 'warning', title: 'Usage at 85%' })
```

</Preview>

## API

| Option | Type | Default |
| --- | --- | --- |
| `title` | `ReactNode` | — |
| `description` | `ReactNode` | — |
| `variant` | `default` `info` `success` `warning` `destructive` | `default` |
| `duration` | `number` milliseconds, `0` to keep it open | `5000`, with errors kept open |

`toast()` returns an id, and `dismissToast(id)` closes it early. `<Toaster />` is
already rendered by the theme; mount it yourself only in a custom layout.

The stack is announced through a polite live region, and the container is
positioned with `bottom-right` by default.
