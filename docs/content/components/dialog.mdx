import { AlertDialog, AlertDialogClose, AlertDialogContent, AlertDialogDescription, AlertDialogFooter, AlertDialogHeader, AlertDialogTitle, AlertDialogTrigger, Button, Dialog, DialogClose, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle, DialogTrigger, Input, Label, Sheet, SheetClose, SheetContent, SheetDescription, SheetFooter, SheetHeader, SheetTitle, SheetTrigger } from 'novon'

All three are modal: they trap focus, dim the page behind them and close on
Escape. Pick by intent rather than by size.

- **Dialog** asks for input or shows detail.
- **Alert Dialog** confirms a decision and cannot be dismissed by clicking away.
- **Sheet** is a dialog anchored to an edge, for filters, navigation or detail.

## API

| Component | Notes |
| --- | --- |
| `Dialog` / `AlertDialog` / `Sheet` | Root. `open`, `defaultOpen`, `onOpenChange`. |
| `…Trigger` | Opens the overlay. Use `render` to style another element. |
| `DialogContent` | Centred popup with a close button. `showClose={false}` removes it. |
| `AlertDialogContent` | Like `DialogContent`, without a close button. |
| `SheetContent` | Edge panel. `side` is `right` by default. |
| `DialogHeader` / `DialogFooter` (`AlertDialog…`, `Sheet…`) | Standard padding and alignment. |
| `DialogTitle` / `DialogDescription` | Required for the accessible name and description. |
| `DialogClose` / `AlertDialogClose` / `SheetClose` | Closes the overlay. |
