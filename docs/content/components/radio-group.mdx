import { Label, RadioGroup, RadioGroupItem } from 'novon'

Use a radio group when every option should be visible at once. If the list is
long, or space is tight, a [Select](/components/select) is the better fit.

## Usage

<Preview title="Basic" description="One value is selected at a time.">

<RadioGroup defaultValue="standard" className="w-full max-w-sm">
  <Label><RadioGroupItem value="standard" /> Standard shipping</Label>
  <Label><RadioGroupItem value="express" /> Express shipping</Label>
  <Label><RadioGroupItem value="pickup" /> Pick up in store</Label>
</RadioGroup>

```mdx

  <Label><RadioGroupItem value="standard" /> Standard shipping</Label>
  <Label><RadioGroupItem value="express" /> Express shipping</Label>
  <Label><RadioGroupItem value="pickup" /> Pick up in store</Label>
```

## API

| Component | Element | Notes |
| --- | --- | --- |
| `RadioGroup` | `div` | Takes `value`, `defaultValue`, `onValueChange`, `name`. |
| `RadioGroupItem` | `span` + input | One option. Needs a `value`. |

Arrow keys move between options, and the whole group is reachable with a single
tab stop, which is the expected radio behavior.
