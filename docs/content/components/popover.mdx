import { Copy } from 'lucide-react'
import { Avatar, AvatarFallback, Button, HoverCard, HoverCardContent, HoverCardTrigger, Input, Popover, PopoverContent, PopoverTrigger, Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from 'novon'

Three floating surfaces with different jobs.

- **Popover** holds interactive content and opens on click.
- **Tooltip** names an icon or control and opens on hover and focus.
- **Hover Card** previews an entity and opens on hover.

## Popover

<Preview title="With a form" description="A popover can hold any interactive content.">

<Popover>
  <PopoverTrigger render={<Button variant="outline" />}>Set dimensions</PopoverTrigger>
  <PopoverContent align="start" className="w-64">
    <div className="flex flex-col gap-3">
      <div className="flex flex-col gap-2">
        <label className="text-sm font-medium" htmlFor="pop-w">Width</label>
        <Input id="pop-w" defaultValue="100%" />
      </div>
      <Button size="sm">Apply</Button>
    </div>
  </PopoverContent>
</Popover>

```mdx

  <PopoverContent align="start">

  </PopoverContent>
</Popover>
```

</Preview>

## API

| Component | Prop | Notes |
| --- | --- | --- |
| `Popover` | `open`, `defaultOpen`, `onOpenChange` | Controlled or not. |
| `PopoverContent` | `align`, `side`, `sideOffset` | Positioning. |
| `TooltipProvider` | `delay` | Wraps one or more tooltips. |
| `TooltipContent` | `side`, `sideOffset` | Positioning. |
| `HoverCard` | `openDelay`, `closeDelay` | Hover timing. |
| `HoverCardContent` | `align`, `side`, `sideOffset` | Positioning. |

A tooltip must never be the only place a piece of information lives, and it must
describe a control that already has an accessible name. The examples above carry
both.
