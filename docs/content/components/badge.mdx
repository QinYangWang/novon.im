A badge is a short, non-interactive status label. Use it when the status needs
to stand apart from surrounding text, not as a container for ordinary metadata.
Always include a text label; color alone must not carry the meaning.

## API

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `default` `secondary` `outline` `success` `warning` `danger` | `default` |
| `xstyle` | `StyleXStyles` | — |

All six variants and existing imports work. Prefer a semantic variant for status
and `xstyle` for typed composition in TSX: it is composed after the base and
variant styles, per property. Native span props, including `ref`, `aria-*` and
`data-*`, are forwarded; `className` and inline `style` are not accepted.

See [StyleX and the design system](/guide/design-system) for a TSX example.
