## What is in it

| Part | Source |
| --- | --- |
| Post list at `/` | Generated from `content/`, newest first |
| A post | One `.mdx` file per post, with `date`, `tags` and an optional cover |
| Tags | `/tags/<tag>` pages, built from frontmatter |
| Feed | `/rss.xml`, from the `rss` plugin |
| About | `content/about.mdx`, an ordinary page |

A post is frontmatter plus a body:

```mdx title="content/hello-world.mdx"
---
title: Hello, world
description: The first post on a brand new novon blog.
date: 2026-01-01
tags: [meta]
image: /cover.svg
---

The body is Markdown, with MDX components available.
```

## Sharing and search

The template ships the same theme controls as the docs template, so the same
`novon.config.ts` keys apply — `theme.social` fills the footer, `theme.darkMode`
adds the toggle, and adding `search` to `plugins` adds the ⌘K palette.
