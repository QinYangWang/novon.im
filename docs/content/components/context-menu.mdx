import { ContextMenu, ContextMenuContent, ContextMenuItem, ContextMenuLabel, ContextMenuSeparator, ContextMenuShortcut, ContextMenuSub, ContextMenuSubContent, ContextMenuSubTrigger, ContextMenuTrigger } from 'novon'

A context menu opens where the pointer is, so it complements the item rather than
replacing a visible control. Always keep a visible way to do the same action.

## Usage

<Preview title="Basic" description="Right-click inside the dashed area.">

<ContextMenu>
  <ContextMenuTrigger className="flex h-32 w-full max-w-md items-center justify-center rounded-xl border border-dashed border-border text-sm text-muted-foreground">
    Right-click here
  </ContextMenuTrigger>
  <ContextMenuContent className="w-52">
    <ContextMenuLabel>Row</ContextMenuLabel>
    <ContextMenuItem>Open<ContextMenuShortcut>↵</ContextMenuShortcut></ContextMenuItem>
    <ContextMenuItem>Duplicate<ContextMenuShortcut>⌘D</ContextMenuShortcut></ContextMenuItem>
    <ContextMenuSeparator />
    <ContextMenuSub>
      <ContextMenuSubTrigger>Move to</ContextMenuSubTrigger>
      <ContextMenuSubContent>
        <ContextMenuItem>Archive</ContextMenuItem>
        <ContextMenuItem>Trash</ContextMenuItem>
      </ContextMenuSubContent>
    </ContextMenuSub>
    <ContextMenuSeparator />
    <ContextMenuItem>Delete</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>

## API

| Component | Notes |
| --- | --- |
| `ContextMenu` | Root. |
| `ContextMenuTrigger` | The region that responds to the secondary click. |
| `ContextMenuContent` | The popup. Positioned at the pointer. |
| `ContextMenuItem` / `ContextMenuCheckboxItem` / `ContextMenuRadioItem` | Actions and choices. |
| `ContextMenuLabel` / `ContextMenuSeparator` | Structure. |
| `ContextMenuSub` / `…SubTrigger` / `…SubContent` | A nested menu. |

The trigger opens on the keyboard's context-menu key as well, so the actions stay
reachable without a pointer.
