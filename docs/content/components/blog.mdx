A blog layer supplies a post list at its root and tags at `<layer>/tags/<tag>`.
A root blog also keeps `/blog` and `/tags/<tag>`. Use these components when
composing a custom homepage or topic index inside a blog layer.

```mdx
## Recent writing

<PostList limit={5} />

## Browse by topic

<TagList />
```

`PostList` accepts an optional `limit` and `title`. It reads titles, descriptions
and dates from frontmatter and links to the published posts. `TagList` links to
the generated topic pages in the current blog layer. Lists never include docs
or another blog layer's posts. Drafts are excluded from production builds.

For a custom React theme, import `PostList`, `PostItem`, `PostCard` and `TagList`
from `novon` and pass the posts or tags from `useSite().site` explicitly.
