import { Button, Field, FieldControl, FieldDescription, FieldError, FieldLabel } from 'novon'

`Field` wires a label, a description and a validation message to one control. It
tracks touched, dirty, filled, focused and valid state and sets the matching
`data-*` attributes, so the surrounding markup can react without extra state.

## Usage

<Preview title="With a description" description="Helper text sits below the control.">

<Field name="workspace" className="w-full max-w-sm">
  <FieldLabel>Workspace name</FieldLabel>
  <FieldControl placeholder="acme" />
  <FieldDescription>Lowercase letters, numbers and dashes.</FieldDescription>
</Field>


## API

| Component | Element | Purpose |
| --- | --- | --- |
| `Field` | `div` | Owns the control's state and attributes. |
| `FieldLabel` | `label` | Associated with `FieldControl` automatically. |
| `FieldControl` | `input` | The control. Pass `render` to swap the element. |
| `FieldDescription` | `div` | Helper text, linked with `aria-describedby`. |
| `FieldError` | `div` | The validation message. |

`Field` also accepts `validate`, a function or promise returning a message, for
custom rules beyond the native constraints.
