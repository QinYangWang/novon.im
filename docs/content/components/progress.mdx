import { Progress, Skeleton, Spinner } from 'novon'

Three ways to say "working": a bar when you know how far along you are, a
skeleton when you know the shape of what is coming, and a spinner when you know
neither.

## Usage

<div className="flex w-full max-w-sm flex-col gap-4">
  <Progress value={25} />
  <Progress value={60} />
  <Progress value={90} />
</div>

```mdx
<Progress value={60} />

```

## API

| Component | Prop | Type | Default |
| --- | --- | --- | --- |
| `Progress` | `value` | `number` | `0` |
| `Progress` | `min` / `max` | `number` | `0` / `100` |
| `Progress` | `indeterminate` | `boolean` | `false` |
| `Skeleton` | `className` | `string` | — |
| `Spinner` | `label` | `string` | `Loading` |

`Skeleton` sets `aria-hidden`, and `Spinner` exposes `role="status"`, so only one
of the two should carry the accessible name for a given region.
