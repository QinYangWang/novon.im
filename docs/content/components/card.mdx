import { Badge, Button, Card, CardAction, CardContent, CardDescription, CardFooter, CardHeader, CardTitle, Input, Label } from 'novon'

A card is the default container for a self-contained unit: a setting, a summary,
a form. Compose it from `CardHeader`, `CardTitle`, `CardDescription`,
`CardContent`, `CardFooter` and `CardAction`.

## Usage

<Preview title="Basic" description="A header, a body and a footer action.">

<Card className="w-full max-w-sm">
  <CardHeader>
    <CardTitle>Deployments</CardTitle>
    <CardDescription>Every push to main ships automatically.</CardDescription>
  </CardHeader>
  <CardContent className="text-sm text-muted-foreground">
    The last deploy finished in 42 seconds.
  </CardContent>
  <CardFooter>
    <Button size="sm">View logs</Button>
  </CardFooter>
</Card>

## API

| Component | Element | Notes |
| --- | --- | --- |
| `Card` | `div` | The rounded, bordered surface. |
| `CardHeader` | `div` | Title block with an optional action. |
| `CardTitle` | `h3` | The card's heading. |
| `CardDescription` | `p` | Muted supporting line. |
| `CardContent` | `div` | The body. |
| `CardFooter` | `div` | Actions row. |
| `CardAction` | `div` | Pushes to the top right of the header. |

<Warning>
  Inside MDX, an un-imported `Card` is the documentation content card. Import
  this one explicitly to get the surface: `import { Card } from 'novon'`.
</Warning>
