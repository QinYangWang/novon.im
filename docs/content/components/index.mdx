Start with Markdown: headings, paragraphs, links, lists, quotes, tables and fenced
code. Add a component only when it makes an explanation easier to follow.

## Organize and illustrate

- [Cards](/components/card): related articles and guide entry points.
- [Media](/components/media): screenshots, captions and video embeds.
- [Tree view](/components/tree-view): nested files, pages or entities the arrow keys can walk.
- [Logo marquee](/components/logo-marquee): a scrolling row of marks that pauses for the reader.
- [Blur-up image](/components/blur-up-image): placeholders that resolve into the photo.
- [Badge](/components/badge): versions and publishing status.
- [Avatar](/components/avatar) and [Blobatar](/components/blobatar): author identities.
- [Blog lists](/components/blog): recent posts and topic links.

These authoring components are available in MDX without imports. Explicit imports
are only needed for lower-level theme primitives such as [Button](/components/button)
and the compound `Table` and `Avatar` components.

## What belongs in the theme?

Search, mobile navigation, theme switching, copy actions, the table of contents
and previous/next links are provided by the layout. You do not need to compose
them inside every article. `Dialog` and `DropdownMenu` remain available for theme
overrides because the built-in layout uses them.

## What was removed?

The application-widget catalog is no longer part of novon: forms (`Input`,
`Textarea`, `Label`, `Field`, `Select`, `Checkbox`, `RadioGroup`, `Switch`, `Slider`),
`Toggle`, `ToggleGroup`, `Alert`, toast notifications, loading widgets (`Progress`,
`Skeleton`, `Spinner`), `Collapsible`, `Breadcrumb`, `Pagination`, `Separator`,
`AspectRatio`, `AlertDialog`, `Sheet`, `Popover`, `Tooltip`, `HoverCard` and
`ContextMenu`. Their unused implementations and exports were removed too.

Use callouts instead of alerts, accordions instead of a second disclosure API,
Markdown rules instead of separators, and the built-in page navigation instead of
pagination widgets. A static site does not supply a subscription, account or
settings backend; examples should not imply that it does.

If an article genuinely needs an interactive calculator, form or demo, import a
purpose-built React component in that page or register it through
[`components` in the configuration](/guide/configuration). Existing custom themes
that imported removed exports must supply their own replacements.
