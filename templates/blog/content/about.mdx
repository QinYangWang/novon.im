A page does not have to be a post. `sidebar: false` keeps it out of the post list
and the feed while still publishing it at its own URL.

## This site

It is a directory of MDX files and one config file:

```text title="project layout"
__NAME__/
├── novon.config.ts
└── content/
    ├── hello-world.mdx     # → /hello-world
    ├── writing-in-mdx.mdx  # → /writing-in-mdx
    └── about.mdx           # → /about   (sidebar: false)
```

The header links to this page from `nav` in `novon.config.ts`.

## Editing

```bash
novon dev     # preview at http://localhost:4321
novon build   # write the static site to dist/
```
