Use accordions for FAQs and background information. Keep prerequisites, warnings
and essential instructions visible in the main text.

<Preview title="Deployment FAQ">
<AccordionGroup>
  <Accordion title="Do I need a server?">No. The build produces static HTML and assets that can be hosted on a CDN.</Accordion>
  <Accordion title="Does a direct link work?">Yes. Every published route has its own generated HTML file.</Accordion>
</AccordionGroup>

```mdx
<AccordionGroup>
  <Accordion title="Do I need a server?">
    No. The build produces static HTML and assets.
  </Accordion>
</AccordionGroup>
```
</Preview>

No imports are required. `Accordion` accepts `title` and optional `icon`.
`AccordionGroup` supports `multiple` when readers should be able to open several
answers at once. Enter or Space opens the focused question.

Custom themes can import `Accordion`, `AccordionItem`, `AccordionTrigger` and
`AccordionPanel` for the lower-level value-based API.
