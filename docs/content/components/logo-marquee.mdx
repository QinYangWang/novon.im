A logo marquee shows a repeated row of partner or product marks. It is the one
moving surface in the kit: it pauses on hover, focus and touch, animates only
near the viewport, and falls back to a static scrollable row under reduced
motion. Never put content a reader must catch inside it.

Items without `href` render as plain text. Items with `href` or an `onSelect`
handler become links or buttons: focus pauses the row and scrolls the focused
mark into view. Copies of the row are `aria-hidden`, so a screen reader hears
each mark once.

## API

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `LogoMarqueeItem[]` — `{ id, label, href?, mark? }` | required |
| `label` | `string` — accessible name | `Logos` |
| `speed` | `number` — pixels per second | `44` |
| `direction` | `left` `right` | `left` |
| `gap` | `number` | `40` |
| `paused` | `boolean` | `false` |
| `onSelect` | `(item) => void` | — |
| `xstyle` | `StyleXStyles` | — |

`mark` replaces the visible label; the label is then kept as hidden text, so
every mark still announces its name. Keep marks visually sized alike.

The motion loop is plain `requestAnimationFrame` over one transform and needs
no animation library. `useLogoMarquee` is exported for custom themes that want
the same measurement, ramping and pause behavior over their own markup.
