import { Avatar, AvatarFallback, AvatarImage, Blobatar } from 'novon'

An avatar shows an image when it loads and falls back to initials or an icon when
it does not. The fallback is not an error state, it is part of the component.

## Usage

<Preview title="With a fallback" description="The initials show until the image resolves.">

<div className="flex items-center gap-3">
  <Avatar>
    <AvatarImage src="https://github.com/shadcn.png" alt="shadcn" />
    <AvatarFallback>SC</AvatarFallback>
  </Avatar>
  <Avatar>
    <AvatarImage src="/does-not-exist.png" alt="" />
    <AvatarFallback>NV</AvatarFallback>
  </Avatar>
</div>

```mdx
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="shadcn" />
```

## API

| Component | Element | Notes |
| --- | --- | --- |
| `Avatar` | `span` | The clipped, rounded frame. |
| `AvatarImage` | `img` | Falls back when it errors or is still loading. |
| `AvatarFallback` | `span` | Rendered whenever the image is not ready. |

Always give the image a meaningful `alt`, and mark it empty when the name is
already next to it so a screen reader does not repeat it.
