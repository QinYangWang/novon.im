Tabs work well for equivalent alternatives. Do not hide required sequential
instructions behind separate tabs; use [steps](/components/steps) instead.

<Preview title="Package managers">
<Tabs>
  <Tab title="bun">Run `bun add novon`.</Tab>
  <Tab title="npm">Run `npm install novon`.</Tab>
</Tabs>

```mdx
<Tabs>
  <Tab title="bun">Run `bun add novon`.</Tab>
  <Tab title="npm">Run `npm install novon`.</Tab>
</Tabs>
```
</Preview>

`Tab` accepts a `title` and optional `icon`. Arrow keys move between tabs. One
indicator slides between the tabs to mark the selection, and focus stays visible
on the row. For fenced code blocks, use [CodeGroup](/components/code) to derive
labels from filenames.

The MDX API needs no import. Custom React themes can import `Tabs`, `TabsList`,
`TabsTrigger` and `TabsContent` from `novon` for explicit `value` control.
