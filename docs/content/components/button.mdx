Buttons communicate the actions a user can take. Pick a variant that matches how
important the action is, and a size that matches the density of the surface.

## API

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `default` `secondary` `outline` `ghost` `destructive` `link` | `default` |
| `size` | `sm` `default` `lg` `icon` `icon-sm` | `default` |
| `disabled` | `boolean` | `false` |
| `static` | `boolean` — disable press scaling | `false` |
| `xstyle` | `StyleXStyles` — composed last | — |

Buttons use a 150 ms color/press transition with a restrained `0.96` scale.
Reduced-motion preferences disable scaling; disclosure and tab controls keep
text stationary. Disabled controls do not animate. The default `type` is `button`.

Every native button attribute except `className` and `style` is forwarded.
Compose one-off treatments with `xstyle`; it is applied after the variant styles
so a specific property override always wins.

<Note>
  Reach for `variant="link"` only for a tertiary action inside a paragraph. For
  navigation, use an anchor rather than a button.
</Note>
