import { Slider } from 'novon'

A slider is best for an approximate value where the exact number matters less
than the position, like volume, opacity or a price ceiling. When the exact value
matters, pair it with an input.

## Usage

<Preview title="Single value" description="Pass an array of one number.">

<Slider defaultValue={[40]} className="max-w-sm" />

```mdx
<Slider defaultValue={[40]} />
```

</Preview>

<Preview title="Range" description="Two numbers render two thumbs.">

<Slider defaultValue={[25, 70]} className="max-w-sm" />

```mdx
<Slider defaultValue={[25, 70]} />
```

</Preview>

<Preview title="With a readout" description="`showValue` prints the current value above the track.">

<Slider showValue defaultValue={[1200]} min={0} max={4000} step={100} className="max-w-sm" />

<Slider showValue defaultValue={[1200]} min={0} max={4000} step={100} />

</Preview>

## API

| Prop | Type | Default |
| --- | --- | --- |
| `defaultValue` / `value` | `number[]` | `[50]` |
| `onValueChange` | `(value: number \| number[]) => void` | — |
| `min` / `max` | `number` | `0` / `100` |
| `step` | `number` | `1` |
| `largeStep` | `number` | — |
| `disabled` | `boolean` | `false` |
| `orientation` | `horizontal` `vertical` | `horizontal` |
| `showValue` | `boolean` | `false` |

Arrow keys move by `step`, Page Up and Page Down move by `largeStep`, and Home
and End jump to the ends.
