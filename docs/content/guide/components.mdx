## In MDX, without an import

These are injected into every `.mdx` file through `MDXProvider`, so they work
without an import. An explicit `import` in a page always wins over the default.

| Component | Purpose |
| --- | --- |
| `Callout`, `Note`, `Info`, `Tip`, `Warning`, `Caution`, `Danger` | Callouts |
| `Card`, `CardGroup`, `Columns` | Link grids and layouts |
| `Steps`, `Step` | Numbered procedures |
| `Tabs`, `Tab`, `CodeGroup` | Tabbed content and code |
| `Accordion`, `AccordionGroup` | Collapsible sections |
| `Frame`, `Badge`, `Icon`, `SvglIcon`, `Term`, `YouTube` | Media and inline bits |
| `Preview` | A live example with its MDX source and a Preview / Code toggle. |
| `PostList`, `TagList` | Site data, no props needed |

### Callouts

<Note>Neutral information that supports the surrounding text.</Note>

<Info title="Custom title">Callouts accept a `title` and an `icon`.</Info>

<Tip>A suggestion, shortcut or best practice.</Tip>

<Warning>Something that will break if ignored.</Warning>

<Danger>Destructive or irreversible.</Danger>

`Callout` takes a `type` of `note`, `info`, `tip`, `success`, `warning`,
`caution` or `danger`, plus an optional `title` and `icon`.

### Inline bits

Badges: <Badge>New</Badge> <Badge variant="secondary">Beta</Badge>
<Badge variant="outline">Draft</Badge> <Badge variant="success">Stable</Badge>
<Badge variant="warning">Deprecated</Badge>

Icons: <Icon icon="Rocket" /> <Icon icon="Shield" /> <Icon icon="Database" />

A defined term: <Term tip="Content Delivery Network">CDN</Term>.

Brand marks: <SvglIcon name="markdown" /> <SvglIcon name="openai" /> <SvglIcon name="claude" />

`SvglIcon` bundles a curated set of brand marks (`markdown`, `openai`, `claude`)
from [SVGL](https://svgl.app) as static assets — no runtime fetch and no
third-party markup. A mark is decorative by default; add `label` when it carries
meaning on its own. It is also exported from `novon` for your own components.

```mdx
<SvglIcon name="openai" />
<SvglIcon name="claude" label="Claude" />
```

### Preview

`Preview` pairs a live example with the MDX that produced it. Put a fenced
`mdx` code block between the tags and it moves into the Code tab, so the source
is written once:

<Preview title="Badge" description="The source is lifted from the fence below.">

<Badge variant="success">Stable</Badge>

```mdx
<Badge variant="success">Stable</Badge>
```

</Preview>

The `title` and `description` props are optional, and `code` takes a string when
you would rather not nest a fence. Every component in the
[reference](/components) is built with it.

## The shared kit

Both templates are assembled from these, and they are exported from `novon` so
your own components and theme overrides can use them.

| Component | Purpose |
| --- | --- |
| `PillNav` | Segmented navigation with an indicator that slides between items. |
| `IconBadge` | Rounded-square icon container used on cards and rows. |
| `Section` | Titled block with the standard vertical rhythm. |
| `Reveal` | Reveals its children on scroll. |
| `ScrollProgress` | Reading progress bar pinned to the top. |
| `ArrowPill`, `SocialPills` | Pill links, and a row built from `theme.social`. |
| `CopyUrlButton`, `PageActions` | Copy the current URL, or the page's Markdown. |
| `ThemeSwitch`, `ThemeToggle` | Three-way and single theme controls. |

```tsx
import { ArrowPill, IconBadge, PillNav, Reveal, Section } from 'novon'

export default function Banner() {
  return (
    <Section title="Announcement">
      <PillNav items={[{ label: 'home', href: '/' }, { label: 'docs', href: '/guide' }]} />
      <ArrowPill href="https://example.com">Read more</ArrowPill>
    </Section>
  )
}
```

<Note>
  `Reveal` only hides its content once JavaScript is running, and both it and the
  nav indicator are disabled under `prefers-reduced-motion`, so nothing is ever
  hidden from a reader without JS.
</Note>

## shadcn/ui primitives

The components novon itself is built from, all on
[Base UI](https://base-ui.com). Every one has a live preview and an MDX snippet
in the [component reference](/components):

- **Surfaces** `Card`, `Badge`, `Avatar`, `Blobatar`, `Table`, `Separator`, `AspectRatio`,
  `ScrollArea`
- **Forms** `Input`, `Textarea`, `Label`, `Field`, `Select`, `Checkbox`,
  `RadioGroup`, `Switch`, `Slider`
- **Feedback** `Alert`, `Toast`, `Progress`, `Skeleton`, `Spinner`
- **Navigation** `Tabs`, `Accordion`, `Collapsible`, `Breadcrumb`, `Pagination`,
  `Toggle`, `ToggleGroup`
- **Overlays** `Dialog`, `AlertDialog`, `Sheet`, `Popover`, `Tooltip`,
  `HoverCard`, `DropdownMenu`, `ContextMenu`

Variant helpers `buttonVariants`, `badgeVariants`, `toggleVariants` and
`alertVariants` are exported for building your own.

```mdx
import { Button, Card, CardContent } from 'novon'

<Card>
  <CardContent>
    <Button variant="outline" size="sm">Click me</Button>
  </CardContent>
</Card>
```

<Warning>
  `Card` inside MDX is the content card from this page. The shadcn/ui container
  is also exported as `Card`, so importing it shadows the built-in.
</Warning>

## Hooks and helpers

| Export | Purpose |
| --- | --- |
| `useConfig()` | The runtime configuration the theme was rendered with. |
| `useSite()` | Config, base path, route table and the current URL. |
| `useBase()` | The configured base path. |
| `useOverride()` | Looks up a theme override by name. |
| `cn()` | `clsx` + `tailwind-merge`. |
| `withBase()` | Joins the base path with a site-relative path. |
| `formatDate()` | Locale-aware dates for feeds and lists. |

```tsx
import { cn, useConfig, withBase } from 'novon'

export default function Version() {
  const config = useConfig()
  return (
    <a href={withBase(config.base, '/guide/cli')} className={cn('underline', 'text-sm')}>
      {config.title}
    </a>
  )
}
```

## Icons

`icon` accepts a name from a curated set, a component, or an element. The set is
deliberately small so it stays tree-shakeable: `Rocket`, `Book`, `FileText`,
`Puzzle`, `Settings`, `Palette`, `Cloud`, `Terminal`, `Layers`, `Zap`, `Shield`,
`Database`, `Globe`, `Tag`, `Search`, `Command`, `Monitor` and about forty more.
`icons` is exported if you need to look one up.

```mdx
<Icon icon="Rocket" />
<Icon icon={MyOwnIcon} />
```
