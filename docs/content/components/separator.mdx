## Aspect Ratio

  <div className="flex size-full items-center justify-center text-sm text-muted-foreground">16 : 9</div>
</AspectRatio>


## Scroll Area

<Preview title="Custom scrollbar" description="A themed, thin scrollbar over native scrolling.">

<ScrollArea className="h-32 w-full max-w-sm rounded-xl border border-border">
  <div className="flex flex-col gap-3 p-4 text-sm text-muted-foreground">
    {Array.from({ length: 12 }, (_, index) => (
      <p key={index}>Line {index + 1}</p>
    ))}
  </div>
</ScrollArea>

```mdx
<ScrollArea className="h-32">
  <div className="p-4">Long content</div>
</ScrollArea>
```

</Preview>

## API

| Component | Prop | Notes |
| --- | --- | --- |
| `Separator` | `orientation` | `horizontal` or `vertical`. |
| `Kbd` | `className` | Sizes to its content. |
| `AspectRatio` | `ratio` | A number such as `16 / 9`. |
| `ScrollArea` | `viewportClassName` | Targets the scrolling element. |
