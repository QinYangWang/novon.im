# SVGL brand marks

Static copies of three marks from [SVGL](https://svgl.app), imported by
`src/runtime/svgl.tsx`. They are bundled as Vite assets — there is no runtime
fetch, and no third-party SVG markup is injected into the DOM.

| File | Source |
| --- | --- |
| `openai.svg`, `openai_dark.svg` | https://svgl.app/library/openai.svg, https://svgl.app/library/openai_dark.svg |
| `markdown-light.svg`, `markdown-dark.svg` | https://svgl.app/library/markdown-light.svg, https://svgl.app/library/markdown-dark.svg |
| `claude-ai-icon.svg` | https://svgl.app/library/claude-ai-icon.svg |

their respective owners and are used only to identify the linked service.
