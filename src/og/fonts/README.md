# OG image font

`NotoSans-Regular.ttf` is bundled for deterministic, offline OG image rendering.
It is not shipped to the browser as a web font.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
License: SIL Open Font License 1.1, reproduced in `OFL.txt`.

This font covers Latin, Greek and Cyrillic, not every writing system or emoji.
Use an explicit `ogImage` for artwork requiring other fonts or scripts.
